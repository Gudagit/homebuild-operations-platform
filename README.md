# HomeBuild Operations Platform

A full-stack construction and property operations management system.

## Purpose

The system helps construction and property management teams track:

- Properties
- Communities
- Construction stages
- Tasks
- Contractors
- Inspections
- Issues and defects
- Deadlines
- Documents
- Completion status
- Reports

## Tech Stack

- Frontend: React + JavaScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- Testing: Pytest + React Testing Library
- API Testing: Postman
- Version Control: Git + GitHub
